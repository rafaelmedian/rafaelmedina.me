# Resource favicons

Self-hosted favicons from the linked websites or their creators’ personal sites.
Superpowers keeps GitHub’s favicon; Review-ready PRs reuses the site’s own
`/favicon-32.png`. Refresh from these original URLs when their branding changes.
Emil’s ICO is converted to a 32px PNG for the 16px display size.

- `craft.png`: https://craft.gustavofior.com/icon.png
- `github.png`: https://github.githubassets.com/favicons/favicon.png
- `transitions.png`: https://transitions.dev/assets/favicon-light-mode.png?v=4
- `interface-craft.png`: https://www.interfacecraft.dev/favicon.png
- `emil.png`: https://emilkowal.ski/favicon.ico
- `jakub.png`: https://jakub.kr/favicon.ico (converted to PNG)
- `ibelick.png`: https://ibelick.com/favicon.png?v=1
